# 00 兩科地圖

考試：**科目一 L11 人工智慧基礎概論**、**科目二 L12 生成式 AI 應用與規劃**。電腦測驗。11/07 場次兩科平均 70、單科不得低於 60。

解題口訣：**考你怎麼選、怎麼擋風險，不是考你背定義。**

## 科目一 L11（五塊，默寫用）

1. **L111 概念與治理** — AI 定義／分類；治理、風險分級、國內外指引
2. **L112 資料** — 來源與型態；收集→清理→特徵→標準化；隱私與安全
3. **L113 機器學習** — 訓練與泛化；監督／非監督／半監督／強化／多模態／深度
4. **L114 鑑別 vs 生成** — 原理、測試驗證、部署與效能；CV／語音／生成場域

## 科目二 L12（三塊，默寫用）

1. **L121 No/Low Code** — 是什麼、優勢、限制、何時不該用
2. **L122 工具與用法** — 文本／圖像／聲音工具；提示工程、RAG、工具整合、Agent
3. **L123 導入** — 評估（含成本效益、選方案）；規劃（目標、資源、測試）；風險（倫理、個資、合規）

## 必考 vs 可後補

| 必考（先拿分） | 可後補 |
|----------------|--------|
| 治理／HITL／高風險場景 | 個別模型內部公式 |
| 資料洩漏、過擬合 | 進階正則化推導 |
| 鑑別 vs 生成任務選擇 | 所有商業工具功能表 |
| Prompt／RAG／何時上 Agent | LoRA 實作細節 |
| 導入順序、個資、幻覺 | 單一廠商最新功能 |
