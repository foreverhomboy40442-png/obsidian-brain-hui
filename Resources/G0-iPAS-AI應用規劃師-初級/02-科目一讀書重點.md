# 3.1 人工智慧概念

## 3.1.1 定義與功能分類

**判斷句：** AI 是讓機器執行原本需要人類智慧的任務（學習、推理、解題、感知）。它是一個領域，不是單一技術；機器學習、深度學習、專家系統都只是其中一塊。

依**功能**分三類（常考對場景，不要只背名字）：

| 類型 | 在做什麼 | 典型產出 | 企業例子 |
|------|----------|----------|----------|
| 分析型 | 從資料找出模式與洞見 | 報表、分群、關聯 | 客群分析、品質異常探勘 |
| 預測型 | 用歷史資料預測未來 | 分數、趨勢、風險 | 流失預測、授信、需求預測 |
| 生成型 | 依提示產出新內容 | 文字、圖、語音、程式 | 客服草稿、方案一頁紙 |

**易混：** ChatGPT 能幫忙分類，不代表「分類題」一定要上生成式。要判定／打分數 → 先想鑑別／預測模型；要產出內容 → 生成式。

AI ≠ 只有深度學習。正確說法：AI 包含機器學習、專家系統、搜尋演算法等。深度學習是機器學習的子集合。

## 3.1.2 企業導入 AI 的常見目標

提高效率、強化決策、個人化服務、促進創新。生成式自 2022 年後大幅改變工作型態，但**高風險決策仍要人在迴路**（見治理）。

## 3.1.3 應用領域（記「場景→技術」，不背廠商）

| 產業 | 常考場景 | 技術方向 |
|------|----------|----------|
| 醫療 | 影像輔助診斷、藥物分子模擬、個人化療程 | CV／生成分子／不可全自動下診斷 |
| 金融 | 信用風險、詐欺即時偵測、演算法交易 | 預測／異常偵測；授信要人覆核 |
| 製造 | 重複作業自動化、影像瑕疵、預測性維護 | 機器人＋CV＋設備時序 |
| 交通 | 自駕、流量預測、路線 | 感測＋強化學習／預測 |
| 娛樂 | 適應性遊戲、VR、內容推薦 | 生成＋推薦系統 |

**公告題考法：** 智慧城市要持續蒐集 PM2.5、垃圾桶滿溢 → 最直接是**感知器網路（Sensor Network）**，不是專家系統或決策支援系統。先問「資料從哪來」。

## 3.1.4 三層架構

1. **技術底層**
   - 資料處理與分析：清理、整合、儲存；ETL；Hadoop／Spark 等大數據平台。
   - 演算法：迴歸、分類、決策樹、基因演算法等。
   - 機器學習：監督／非監督／強化。
   - 深度學習：多層神經網路，處理影像、語音、NLP；框架如 TensorFlow、PyTorch。
   - 專家系統：規則＋知識庫，模擬專家決策（醫療、財務）。
2. **開發應用：** 模型設計 → 訓練 → 測試 → 部署，對準業務需求。
3. **實際運用：** 行業方案、產品服務、流程優化。

**判斷：** 「先選模型品牌」通常錯；先對準資料與任務，再選底層技術。

## 3.1.5 資料型態與蒐集

| 型態 | 特徵 | 例子 |
|------|------|------|
| 結構化 | 固定欄位、列存 | 關聯式資料庫、規範化試算表 |
| 半結構化 | 有標籤、格式較彈性 | JSON、XML、CSV |
| 非結構化 | 無固定 schema | 圖、影音、郵件、自由文本 |

蒐集方法：問卷調查、自有產品／裝置數據、公開 API、付費第三方、網路爬蟲（公開頁面）。規劃時同時問：**授權、個資、能不能外流**。

## 3.1.6 資料清洗

目的：處理遺缺、重複、錯誤、不一致。

- **遺缺：** 均值／中位數／眾數填補、插補、用模型預測；缺太多才刪列（會傷代表性）。
- **重複：** 用主鍵或關鍵欄位識別，留一份。
- **錯誤值：** 超出合理範圍（年齡 -5）、拼寫錯誤。
- **離群值：** 可能是錯，也可能是有意義的極端事件（高額理賠）。**不要一律刪。** 先用 Z-score／IQR 評估，再依業務決定調整或保留。公告題：常態資料裡少數極端高額案件，最不適當的是不評估就粗暴刪掉或破壞整體分佈。

**資料整合（Data Integration）目的：** 統一格式與欄位、去重、整併多源以提升完整性。**不是**為了依保存政策延長原始資料留存期限。

## 3.1.7 資料轉換

- 格式轉換（CSV↔JSON）
- 型別轉換（字串→數值）
- **正規化／標準化：** 縮放到可比範圍，消除單位差異（Min-Max、Z-score）
- 離散化：連續變數切區間（年齡→青／中／老）
- 縮減：特徵選擇、特徵提取、**PCA** 降維

類別編碼：無序類別用 One-hot；Label encoding 可能被模型當成有大小順序。

## 3.1.8 四種分析（必考對任務）

| 分析 | 問題 | 工具印象 |
|------|------|----------|
| 敘述性 Descriptive | 發生了什麼？ | 平均、中位數、標準差、百分位、直方圖、散佈圖、折線圖 |
| 探索性 Exploratory | 有什麼模式／異常？不預設假設 | 散佈圖矩陣、熱圖、平行座標、盒鬚圖、相關、分群、PCA、異常偵測 |
| 診斷性 Diagnostic | 為什麼發生？ | 向下鑽取、關聯（Apriori／購物籃）、因果（A/B、因果圖） |
| 預測性 Predictive | 接下來會怎樣？ | 迴歸、分類、時間序列（ARIMA／LSTM）、集成（RF／GBM／XGBoost） |

**EDA vs CDA：** EDA 靈活探索、生成假設；CDA（驗證性）驗證假設、做分類／分群／相關／預測。不要把「先畫圖看看」說成驗證性。

敘述統計選指標：

- 平均：好算，**怕極端值**。
- 中位數：不怕極端值；房價有豪宅時用它。
- 眾數：最常見類別；可能多個或不存在。
- 標準差：分散程度；品管上標準差大 → 製程不穩、良率差。
- 百分位：描述分佈，較不受極端值左右。
- 直方圖：看分佈；組距選不好會誤導。
- 散佈圖：兩變數關係。
- 折線圖：時間趨勢；不適類別比較。
- **雷達圖不適合做資料分佈估計**（指引練習題）。

偏態口訣：

- 平均 **>** 中位數 → 常為**正偏**（右尾長，被大值拉平均）。
- 平均 **<** 中位數 → 常為**負偏**。

## 3.1.9 搜尋演算法

- **線性搜尋：** 從頭比到尾。未排序也可用。
- **二分搜尋：** 資料必須已排序；比中間、砍一半。
- **DFS：** 沿一條路走到盡頭再回溯。
- **BFS：** 一層一層擴散。

## 3.1.10 三個基礎模型

**線性迴歸：** 預測連續值（房價、銷額）。假設線性；非線性擬合差。找一條最貼資料的直線／超平面。

**邏輯迴歸：** 名字有迴歸，其實是**分類**。Sigmoid 把輸出壓成 0–1 機率，再設閾值（如 0.5）。優點：好懂、有機率意義。基本型是二元，多類要擴展。

**KNN：** 看最近的 K 個鄰居。分類用多數決；迴歸用平均或中位數。K 是鄰居數，不是群數（群數是 K-means 的 K）。

## 3.1.11 機器學習步驟與學習類型（3.1 已出現，3.3 再加深）

步驟：（1）準備資料（蒐集、去雜訊、前處理）→（2）訓練並調參 →（3）測試評估，不好就換模型重來。資料愈多且處理愈完整，通常愈好。

| 類型 | 要不要標籤 | 任務 | 例子 |
|------|------------|------|------|
| 監督式 | 要 | 分類、迴歸 | 垃圾信、房價 |
| 非監督式 | 不要 | 分群、降維、異常 | 客群、壓縮 |
| 強化學習 | 獎懲 | 與環境互動、最大化累積獎勵 | 圍棋、自駕 |

非監督式**不是**「學習輸入與既定標記的對應」——那是監督式。

## 3.1.12 深度學習三經典

**CNN：** 影像。卷積抽局部特徵 → 池化降維防過擬合 → 全連接做分類／迴歸。層次特徵：邊緣 → 物體。應用：人臉、MNIST、物件偵測、醫學分割。

**RNN：** 序列。有記憶，適合語音、文本。缺點：梯度消失／爆炸、長序列慢。改良：**LSTM**（遺忘／輸入／輸出門）、**GRU**（較簡、效果常接近）。現代長依賴與 NLP 多改走 Transformer。

**GAN：** 生成器生假資料、判別器辨真假，互相對抗。優點：高品質樣本。缺點：訓練不穩、**模式崩潰（Mode Collapse）**、算力大。應用：草圖轉寫實圖、語音合成。GAN 結果**不是**高度可解釋。

## 3.1.13 生成式模型怎麼練

原理：學文字（或資料）的機率分布，依提示逐 token 接下去。參數愈多，通常愈能捕捉細微差異。

兩階段：

1. **預訓練：** 大量資料 → 清洗 → 向量化 → 選模型（GAN／VAE／Transformer）→ 損失＋優化器（Adam、SGD）迭代到收斂。
2. **微調：** 用領域資料再練；調學習率、batch；可加任務層；資料增強。

影響效果：資料品質與多樣性、模型結構、超參數、計算資源。

生成式**最核心能力**是生成新的、原創的內容，不是「會算數學」或「會控制機器人」。重要基礎是**神經網路**，不是決策樹或線性迴歸。

## 3.1.14 治理與透明（公告題常考）

- 高風險（醫療診斷結論、自動拒貸、自動裁員）→ **Human-in-the-loop**，準確率高也不能無人審核。
- 透明：對受影響的人講得懂；適當對外揭露（報告、技術文件、網站），不是「全部保密」或「只跟內部講」。
- 公平：訓練資料偏誤會變成歧視；要補資料、審核、監控。
- 國際合作：標準、防濫用、技術移轉——「以上皆是」類題出現時通常對。
- 台灣情境：公部門對照數發部手冊思路；金融對照金管會金融業 AI 指引。

**資料隱私技術（規劃判斷）：**

| 做法 | 一句話 |
|------|--------|
| 去識別化 | 拿掉直接認人欄位，仍可能再識別 |
| 差分隱私 | 加噪音，單筆難反推 |
| 聯邦學習 | 資料不動、模型動 |

**Data leakage：** 測試集或未來資訊混進訓練 → 分數虛高、上線崩。時序資料亂打散是經典陷阱。

# 3.2 資料處理與分析概念（統計必配勘誤）

## 3.2.1 中央趨勢

- **平均數：** 算術平均最常用；易被極端值拉走。另有幾何、調和平均，考場以算術為主。
- **中位數：** 排序後正中；不怕極端值；複雜推導較不便。
- **眾數：** 出現最多次；不受極端值；可能多個或沒有。類別資料常用眾數。

## 3.2.2 分散度（含勘誤）

- **四分位數：** 排序後切四等分的三個切點。
- **全距 Range：** 最大減最小；只看兩端，不精確，怕極端值。
- **IQR：** Q3 − Q1。描述中間 50%。指引原文說「與全距有一樣的缺點」，練習題正確選項是「IQR 是 Q3 與 Q1 的差」。解題：IQR **較不受**極端值影響（相對平均、全距）。若選項寫「IQR 會受極端值影響」通常是陷阱。
- **平均差 Mean Deviation（勘誤）：** 所有觀察值與平均數之間**絕對差值的平均**。越大越分散。不是只說「差距」而不提絕對值與平均。
- **標準差：** 點離平均的遠近。品管：標準差顯著偏大 → 製程波動大、品質不穩。
- 變異係數等：用來比較不同單位或不同平均水準的分散。

## 3.2.3 抽樣變異與統計推論（勘誤）

**抽樣變異：** 從母體抽樣算出的統計量（樣本平均、樣本標準差），因樣本隨機性而與母體參數不同，這種變動叫抽樣變異。

機率模型用來刻畫這種變異，才能做區間估計與假設檢定。

**統計推論（勘誤）：** 根據樣本資料，判斷是否接受或拒絕統計假設的過程。

## 3.2.4 統計方法粗分

- 無因果取向：敘述統計、交叉、卡方、PCA、因素分析、集群、相關。
- 有因果／預測取向：羅吉斯迴歸、區別分析、迴歸、變異數分析、PLS 等。  
相關 ≠ 因果。診斷分析才認真做因果（實驗、A/B）。

## 3.2.5 假設檢定名詞（表已勘誤）

流程：猜想 → 蒐集資料 → 檢定決策（接受或拒絕）。

| 名詞 | 要記住的意思 |
|------|----------------|
| H0 虛無假設 | 沒有顯著效果／差異，檢定的基準 |
| Ha 對立假設 | 有顯著效果／差異 |
| 簡單假設 | 參數完全指定 |
| 複合假設 | 只指定部分參數 |
| 接受域／拒絕域 | 讓 H0 被接受／被拒絕的樣本結果集合 |
| 顯著水準 α | 事先容許的 Type I 上限，常取 0.1／0.05／0.01 |
| 檢定統計量 T | 用樣本算出來決定是否拒絕 H0 |
| p 值 | H0 為真下，出現「至少跟觀測一樣極端」的機率。p < α → 拒絕 H0 |

**錯誤表（勘誤後，必背）：**

|  | H0 為真 | H0 為假 |
|--|---------|---------|
| 接受 H0 | 正確 | Type II（β）漏放 |
| 拒絕 H0 | **Type I（α）** 冤案 | 正確（檢力） |

原文表格曾把「拒絕 H0 且 H0 為真」誤寫成 Type II。正確是 **Type I**。

**p＝0.03、α＝0.05（勘誤後說法）：** 在 **95% 信心水準下拒絕**虛無假設。

- 不是「有 97% 信心」（1−0.03 的誤用）。
- 不是「這次犯錯機率就是 5%」。5% 是事先設定的 Type I **上限**，不是這次實際犯錯機率。
- p < α 所以**可以拒絕** H0，不是「無法拒絕」。

## 3.2.6 K-means（3.2 練習＋勘誤）

做法：指定 K 個中心 → 點分配到最近中心 → 更新中心 → 反覆，最小化平方誤差。

正確特徵：

- 希望 K 個**互不重疊**的群。
- 起始中心不同，結果可能不同。
- **容易受雜訊與離群值影響**中心。
- 適合**球形、大小密度接近**的群。
- 不適合明顯非球形、密度差很大、很多離群。
- 常與 **PCA（降維）、Elbow（選 K）** 搭配，使用上有彈性。
- 原理**相對簡單**，不是「比其他集群法複雜」。勘誤：練習第 3 題「並非特點」應選「原理相對複雜」。

K-means **不擅長直接處理類別型資料**（「可以處理類別型」是不正確敘述）。

K ＝ 要分成幾群，不是特徵數、樣本數、迭代次數。

# 3.3 機器學習概念

## 3.3.1 原理與挑戰

機器學習：從資料學規律，**沒見過的資料也要準**（泛化），不是背訓練集。三大類型：監督、非監督、強化。

優勢：資料驅動、可處理非結構化、可隨資料擴展。

挑戰（常考「還要管什麼」）：資料品質不均、標註貴、**解釋性不足**、隱私與倫理、偏見造成歧視。醫療／法律尤其要能解釋。

未來方向：可解釋、公平去偏、跨領域整合。

## 3.3.2 監督式：常見模型

- **線性迴歸：** 連續值。
- **SVM：** 找最大間隔超平面；核函數處理非線性。二元分類常用；醫療影像良惡性等。
- **神經網路：** 非線性、複雜資料；語音轉文字等。
- **決策樹：** 規則清楚，**可解釋性好**（指引練習強調這點）。
- **隨機森林：** 多棵樹投票／平均；Bootstrap 抽樣；降過擬合、較穩。

監督式特點：每個樣本有輸入＋標記；學 mapping。

## 3.3.3 非監督式

聚類（K-means、層次）＋降維（PCA）。市場區隔、異常偵測、影像壓縮、基因資料。不靠事先標籤。

## 3.3.4 強化學習細節

三要素：**Agent、環境、獎勵**。目標最大化累積獎勵。適合動態、重複互動、長期規劃（圍棋、自駕）——指引練習第 1 題答案。

流程：狀態 → 依策略選行動（探索 vs 利用）→ 環境給新狀態與獎勵 → 更新策略。

- **Q-Learning：** 學每個（狀態, 行動）的長期價值 Q，選 Q 最大的行動。
- **DQN：** 用深度網路近似 Q，因狀態太多無法用 Q 表。搭配經驗回放、目標網路穩定訓練。

## 3.3.5 機器學習三階段

1. **資料處理：** 清洗（均值／中位數填補、刪高缺失、IQR 或標準差處理異常）→ 標準化（Min-Max 映到 0–1；Z-score）→ 特徵選擇／降維。
2. **模型訓練：** 選演算法、損失函數、優化器；**梯度下降**用來更新參數、最小化損失。
3. **評估與優化：** 訓練／驗證／測試切分；交叉驗證估泛化；調超參數。

**過擬合：** 訓練很好、測試很差（高 variance）。原因常是模型太複雜或資料不夠、學到雜訊。處理：更多資料、簡化模型、**正則化（L1／L2）**、Dropout、早停、資料增強。指引練習：降低過擬合「通常」選增加正則化項（選項若同時有「增加模型複雜度」那是反效果）。

**欠擬合：** 訓練測試都差（高 bias）→ 模型太簡單或特徵不夠。

**交叉驗證目的：** 較穩地估泛化、減少單一次切分的運氣，協助選模型／超參。

## 3.3.6 評估指標陷阱

- 只看 Accuracy：類別不平衡會騙人（99% 負例全猜負例也很高）。
- 看 Precision／Recall／F1、混淆矩陣。
- 高分先問：切分有沒有 leakage？時序有沒有用未來？

L1（Lasso）讓權重稀疏、有特徵選擇味道；L2（Ridge）讓權重平滑。

深度學習與監督式**不互斥**：CNN 影像分類仍是監督式。

機器學習三核心要素常見考法：**資料、演算法（模型）、計算能力**（或資料／模型／評估，依選項選最完整的一組）。

# 3.4 鑑別式 AI 與生成式 AI

## 3.4.1 一句話分邊

| | 鑑別式 DAI | 生成式 GAI |
|--|-----------|-----------|
| 學什麼 | 條件機率 P(y\|x)，找決策邊界 | 聯合／邊際分佈 P(x,y) 或 P(x)，再抽新樣本 |
| 輸出 | 類別、分數、偵測框 | 新的文字、圖、聲音、程式 |
| 同一輸入 | 應盡量穩定同一判斷 | **允許變異**（同一 prompt 不同輸出是特徵） |
| 風險 | 偏誤、誤判成本、漂移、標註成本 | 幻覺、智財、洩密、不可控、算力 |
| 驗證 | 標註集、混淆矩陣、上線監控 | 人工抽樣、引用、紅隊、回歸測試 |

生成使用者會反覆改 prompt，直到任務可接受——這叫提示工程，不是模型壞掉。

## 3.4.2 鑑別式模型速查

- 邏輯迴歸：二元分類、MLE、閾值。
- SVM：最大間隔＋核。
- 決策樹：資訊增益／吉尼；好解釋。
- 隨機森林：集成、穩。
- 神經網路：反向傳播調權重；影像／語音／自駕感知。

## 3.4.3 生成式模型速查

- **GAN：** 生成器 vs 判別器。StyleGAN 人臉、風格遷移、稀缺病變影像、VR 場景。
- **VAE：** Encoder 壓到隱空間、Decoder 重建；平滑、可做異常檢測（偏離學過的正常分佈）、缺損修復。
- **擴散模型：** 加噪到高斯再逐步去噪還原。高解析圖像、文生圖。
- **Transformer／LLM：** 自注意力、可平行；現代 NLP 主力。

## 3.4.4 整合應用（規劃題高分）

生成負責造資料／造內容，鑑別負責判斷。

- 醫療：GAN 補稀缺病變圖 → CNN 分類。
- 金融：生成壓力情境 → 鑑別風險。
- 自駕：生成惡劣天氣場景 → 鑑別決策。
- 客服：鑑別意圖／情緒 ＋ 生成回覆；知識要準就加檢索。
- 語音：ASR（鑑別）＋ TTS（生成）。
- 教育／智慧城市：生成多樣情境，鑑別做個人化或預警。

**規劃口訣：** 要判定走鑑別；要產出走生成；兩者常串。不要為了生成而生成。小鑑別模型可能比 LLM 分類更便宜、更穩。

上線後準確率掉 → 先查**資料漂移**、資料品質、標籤定義是否變了，再重訓或改規則。

## 3.4.5 可解釋 AI（XAI）——公告試題必考，指引較薄

目的：讓人理解「為什麼這樣判」，高風險（授信、醫療、合約風險）幾乎必問。

| 技術 | 是什麼 | 選它的時候 |
|------|--------|------------|
| 內建可解釋（Intrinsic） | 模型本身透明（線性、淺決策樹） | 要從頭到尾可追規則 |
| LIME | **局部**、模型無關：在該筆資料附近，用簡單代理模型近似黑盒子 | 解釋**這一筆**為什麼被拒貸 |
| SHAP | 用 Shapley 值把預測拆成各特徵的貢獻（可加總） | 要看各特徵對分數的貢獻方向與大小 |
| 顯著性圖 Saliency Map | 看輸入哪些位置對輸出影響大（影像像素、文本 token） | 醫師要看「模型盯哪裡」 |
| 反事實 Counterfactual | 「若某特徵改成這樣，決策就會翻轉」 | 對客戶溝通：收入再高 10 萬可能通過 |

**易混：**

- LIME 的代理模型是**局部近似**，不是把整個黑盒子變成一棵全球決策樹。
- SHAP 不是準確率指標，是**特徵貢獻**。
- 對客戶講反事實，對工程師才堆 SHAP 圖。
- 「準確率高」不能取代解釋與申訴機制。

## 3.4.6 科目一解題習慣

1. 先劃任務：分析／預測／生成？監督／非監督／強化？
2. 資料：型態、清不乾淨、有沒有 leakage、能不能出域。
3. 「最不適當」常常是：高風險全自動、刪離群不評估、用錯圖（雷達圖看分佈）、把相關當因果、K-means 處理類別、p 值解釋成 97% 信心。
4. 治理：人、透明、公平、問責。

## 科目一閉卷清單

- 分析／預測／生成各舉一個樂雲或客戶場景。
- 結構化／半／非結構化各一例。
- 四種分析對任務。
- Type I／II 表、p 與 α、平均差定義。
- K-means：簡單、怕離群、球形、K＝群數。
- 過擬合 vs 欠擬合。
- DAI vs GAI 輸出差在哪。
- LIME／SHAP／顯著性圖／反事實各一句。

# 補篇 A｜訓練細節（指引 3.3 後半，公告題會考）

## A.1 標準化兩個公式（不考手算，考「何時用、洩漏」）

**Min-Max：** 把值映到 0–1。公式：scaled = (x − min) / (max − min)。

**Z-score：** 轉成平均 0、標準差 1。公式：scaled = (x − 平均) / 標準差。

對梯度下降類演算法，特徵量尺差很大時一定要做。  
**評估正確性：** min/max 或 μ/σ 只能用**訓練集**算，再套到驗證／測試。用全資料算再切分 = 另一種 leakage。

金額類右偏很大時，常先取 log 再標準化，比直接砍極端值更不破壞分佈。

## A.2 特徵選擇三法

| 方法 | 做法 | 印象 |
|------|------|------|
| Filter | 用相關、統計量先篩（Pearson） | 快、不管後續模型 |
| Wrapper | 用模型分數評估特徵組合（RFE） | 準但慢 |
| Embedded | 模型自己選（LASSO／L1） | 訓練時順便做 |

降維主力仍是 PCA：壓縮冗餘、保留主要訊息。

## A.3 損失與優化器

損失 = 預測跟答案差多少。訓練就是用優化器把損失壓下去。

- **MSE：** 迴歸，平方誤差平均。
- **交叉熵：** 分類，比機率分佈。
- 輸出要「各類機率且加總為 1」→ Softmax（推薦多類、影音類型預測）。

優化器：

- **BGD：** 整批資料算一次梯度，穩但慢。
- **SGD：** 一筆就更新，快但不穩。
- **Adam：** 自適應學習率，實務最常見。

梯度下降的用途：**更新參數、最小化損失**，不是拿來降雜訊或減計算量。

過擬合防範組合：L1／L2、Early Stopping（驗證集開始變差就停）、Data Augmentation（旋轉翻轉等）。

## A.4 評估與調參

| 指標 | 何時 |
|------|------|
| Accuracy | 類別大致平衡 |
| Precision | 誤報代價高（亂抓詐欺傷害客戶） |
| Recall | 漏報代價高（癌症篩檢、洗錢漏放） |
| F1 | 不平衡、要 Precision 與 Recall 折衷 |
| MSE | 迴歸 |

醫院篩癌要盡量找出所有可能患者 → 重視 **Recall**（降漏診／False Negative）。  
詐欺極少、模型全猜正常也能高 Accuracy → 改看 Recall／F1，或用 **SMOTE** 等合成少數類（仍要小心合成樣本不像真詐欺）。

**K-fold：** 切 K 份，輪流當測試，平均分數。目的是較穩估泛化、**降低過擬合帶來的誤判**（指引練習選此方向），不是加速訓練。

調參：Grid Search 窮舉；Random Search 高維較划算；Bayesian Optimization 用歷史結果接著找。

## A.5 學習類型補丁（公告題愛考「配對」）

| 情境 | 選 |
|------|----|
| 有五年已標註洗錢／正常交易 | 監督式分類 |
| 葉片影像只有 30% 有標籤 | **半監督式**（用無標資料幫忙） |
| 影像裡標出煙霧位置與範圍 | 物件偵測／分割，不是只做整張分類 |
| 設備感測無完整異常標註、找不像平常的型態 | 非監督異常偵測 |
| 車隊調度依狀態拿獎勵 | 強化學習 |
| 客服 LLM 要更符合組織規範與偏好 | **RLHF**（人類回饋強化學習），不是再做一次非監督分群 |
| 少量標註＋大量相似產品經驗可遷移 | 遷移學習 |
| 同時用文字通報＋路口影像＋車流 | 多模態；先整合再建模 |

結構化預測：輸出是有結構的（序列標註、語法樹、路徑），不是單一類別。判斷「這張圖是貓」是普通分類。

CNN 最適合：影像空間結構（PCB 瑕疵、葉片、安全帽）。時序到站預測更常是時間序列／LSTM／表格＋路況特徵，不是硬套 CNN。

訓練誤差幾乎不降、梯度傳不動 → 懷疑梯度消失；方向是更好的活化、殘差、正規化、換 LSTM／Transformer，不是再加深沒處理的 RNN。

## A.6 推論架構

- **即時推論：** 低延遲（詐欺當下、自駕、對話）。
- **批次推論：** 可等、一次算大量（夜間流失評分、報表）。
- LLM **Batching：** 把多個請求湊一批提高 GPU 利用率；可能讓單筆等待變長。高併發要吞吐時合理，極低延遲場景要權衡。

弱 AI 專才、強 AI／AGI 通用：考場幾乎都是弱 AI。某視覺模型只會特定瑕疵 → 換新品種要重訓或遷移，不是已經是通用智慧。

## A.7 生成式補丁（科目一也會考）

對話型工具基礎多是 **Transformer／LLM**，不是決策樹。  
服裝設計要多樣高品質圖 → 擴散或 GAN 類生成，不是 SVM。  
會議摘要用生成；再加一套評估正確性 → 鑑別／檢查模型，兩者整合。  
VAE 適合「依既有圖像產生有變化且連續可調的樣本」（隱空間插值）。  
Flash Attention：加速 Transformer 注意力運算、降記憶體，不是改成 RNN。

# 補篇 B｜指引風格自測（先自己選再看答案）

以下改寫自指引各節評量方向，用來閉卷，不是公告試題原文。

## B.1 概念

1. 圍棋、自駕這種動態重複互動 →？（強化學習）  
2. AI 是否等於深度學習？→ 否，還包含 ML、專家系統等。  
3. 提升透明性：對外揭露報告／文件／網站，不是全面保密。  
4. 不適合作分佈估計：雷達圖。  
5. K-means 的 K：群數。  
6. 降過擬合常見項：加正則化（也可更多資料；加複雜度是反效果）。  
7. 生成式最核心：生成新內容。  
8. 生成式重要基礎：神經網路。  
9. 治理國際合作：標準、防濫用、技術移轉，常為「以上皆是」。

## B.2 統計

1. K-means「不正確」：可以處理類別型。  
2. 製程標準差顯著偏大：品質不穩。  
3. 「並非」K-means 特點：原理比別的集群複雜。（勘誤）  
4. CDA 相對 EDA：驗證假設並深入挖。  
5. 房價有豪宅：用中位數。  
6. 平均 < 中位數：負偏。  
7. p=0.03、α=0.05：95% 信心水準下拒絕 H0。（勘誤）  
8. 平均 > 中位數：正偏。  
9. IQR：Q3−Q1。  
10. 類別最常見值：眾數。

## B.3 機器學習

1. 三核心要素：數據、模型、損失函數。  
2. 監督式：資料含標記。  
3. 過擬合主因：過度學習雜訊。  
4. 交叉驗證：降低過擬合風險／較穩估泛化。  
5. 梯度下降：優化參數以最小化損失。  
6. 線性迴歸最適：銷售額等連續預測。  
7. 決策樹最大優勢：可解釋。  
8. 神經網路差別：多層學複雜特徵。  
9. GAN 正確：生成器＋鑑別器。  
10. 隨機森林：多棵樹投票／平均。

## B.4 鑑別 vs 生成

1. 鑑別式主要目標：分類或迴歸。  
2. 生成式模型例子：GAN（SVM／邏輯迴歸／RF 是鑑別）。  
3. 生成式應用包括合成資料、模擬分佈、創作；不包括「只做決策邊界分類」。  
4. 整合價值：生成補資料、鑑別做判斷；客服生成回覆＋鑑別過濾不當內容。

# 補篇 C｜公告題考法判斷卡（科目一）

不要背題號，背「看到關鍵字選什麼」。完整題在 [[04-題本]]。

**資料**

- 資料整合目的不含「延長保存期限」。
- JSON／XML 是半結構化；MySQL 訂單是結構化；郵件圖片是非結構化。
- 正規化／標準化的統計量用訓練集。
- 無序類別不要當有大小的數字；需要互動可用 feature crossing 或樹模型。
- 稀疏類別＋數值並存：樹模型或 embedding，不要只 One-hot 爆炸後硬塞淺線性。
- 直方圖：看單一連續變數分佈（年齡）。散佈圖：兩變數。折線：時間。
- 已排序陣列找值：二分搜尋。

**治理與醫療金融**

- 金融對消費者互動：要揭露使用 AI、影響、申訴等；不必揭露模型原始碼或權重當「必要項」（依選項選「非必要」）。
- 公部門釋出可能認人的資料：去識別仍可能再識別，要最小化、審查、法律依據。
- 高風險用人覆核＋可解釋＋申訴。

**XAI 速配**

- 解釋「這一筆」→ LIME（局部代理）。
- 特徵貢獻可加總 → SHAP。
- 影像／文本哪裡被盯 → 顯著性圖。
- 對客戶說「怎樣改就過關」→ 反事實。
- LIME 屬模型無關的**事後局部**解釋，不是 Intrinsic 內建透明模型本身。

**技術選型速配**

- 訓練 98%、測試差很多 → 過擬合。
- 類別極不平衡還只看 Accuracy → 錯。
- 只要區域位置 → 偵測／分割，不是分類。
- 缺標註 → 半監督或非監督，不要假裝已有完整標籤。
- 工廠要快驗證、缺 AI 人力 → No/Low Code 或現成服務試點（科目二也考，科目一綜合題會出現）。

# 補篇 D｜整合應用再記一遍
