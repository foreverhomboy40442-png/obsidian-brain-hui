# L113 機器學習

## 判斷句

- 機器學習：用資料找出可泛化的規律，目的是**沒見過的資料也要準**，不是背訓練集。
- 訓練很好、測試很差 → **過擬合（高 variance）**。訓練測試都差 → **欠擬合（高 bias）**。
- 先選**任務類型**，再選模型家族。

## 學習類型

| 類型 | 有沒有答案標籤 | 典型用途 |
|------|----------------|----------|
| 監督式 | 有 | 分類、回歸（流失、用量預測） |
| 非監督式 | 無 | 分群、異常、降維 |
| 半監督式 | 少量標籤 | 標註貴、資料多 |
| 強化式 | 獎懲 | 序列決策、操作策略 |
| 多模態 | 跨文字／圖／聲 | 文件+截圖一起理解 |
| 深度學習 | 多層網路 | 影像、語音、大規模語言 |

## 模型對任務（初級秒殺）

| 任務 | 常選 |
|------|------|
| 影像分類 | CNN |
| 物件偵測 | YOLO 等偵測模型 |
| 短時序／語音序列 | RNN 概念 |
| 較長依賴 | LSTM／Transformer |
| 現代 NLP／LLM | Transformer、Self-Attention、可平行運算 |

## 正則化（知道差別即可）

- L1（Lasso）：權重變稀疏 → 有特徵選擇味道。
- L2（Ridge）：權重變平滑，比較不會單一特徵爆炸。

## 評估陷阱

- 只看 Accuracy：類別不平衡會騙人。
- 看到高分先問：切分方式？有沒有 leakage？要不要 Precision／Recall／F1？

## 易混

- 深度學習是方法家族，不是跟「監督式」互斥（CNN 分類仍是監督式）。
- 強化學習不是「沒標籤的監督式」。

## 樂雲場景

要預測客戶是否續約：監督式分類。要從日誌找異常用量：可能非監督異常偵測。要自動寫方案：生成式（L114／L12），不是亂套 CNN。

## 自測

1. 訓練 99%、測試 61%，優先懷疑什麼？可怎麼處理（方向）？  
2. 沒有標籤、要把客戶分成幾群做經營，哪種學習？  
3. 影像「有沒有安全帽」vs「帽子在畫面哪裡」，模型方向差在哪？

參考：1 過擬合；簡化模型、更多資料、正則化、早停 2 非監督分群 3 分類 vs 偵測
