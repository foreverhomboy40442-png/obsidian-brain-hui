# W1 練習題

閉卷。每題寫「選什麼＋一句理由」。週五目標：20 題錯 ≤ 6。

## 科目一

1. 全自動決定錄取且無人覆核，最先違反哪類治理要求？  
2. 訓練準確率極高、測試很差，最像？  
3. 時序預測卻把未來資料打散進訓練集，問題名稱？  
4. 城市名編成 1,2,3，主要風險？  
5. 「這張圖有沒有安全帽」偏向鑑別還是生成？  
6. 醫院資料不能集中、還想一起訓練，較接近？  
7. 對客戶解釋拒貸，較適合工程 saliency 還是反事實說明？  
8. CNN 較常對應影像分類還是長期文本依賴？  
9. 訓練測試都差，較像過擬合還是欠擬合？  
10. 客服 Chatbot 與自動裁員，哪個較需 HITL？

## 科目二

11. 內部規章常改、要降低胡謅，優先 RAG 還是從零訓練？  
12. RAG 答非所問，先換大模型還是先查切塊與檢索？  
13. 簡單格式仿寫，Few-shot 還是 ToT？  
14. 要穩定少創意，temperature 調高還是調低？  
15. 固定三步表單流程，一定要 Agent 嗎？  
16. No Code 試點後直接當核心計費，主要風險？  
17. 只比較 token 單價、不算覆核人力，忽略了什麼？  
18. 把客戶名單貼進公有 LLM，第一個風險？  
19. MCP 比較像「新模型」還是「接工具的協定」？  
20. 導入第一步應是選 ChatGPT 還是釐清問題與資料？
