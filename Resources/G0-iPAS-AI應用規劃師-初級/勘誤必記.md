# 勘誤必記

來源：官方《學習指引勘誤表》114.04。讀科目一 3-25～3-32、科目二 3-32 前先看這頁。

## 科目一

1. **平均差（Mean Deviation）**  
   是所有觀察值與平均數之間**絕對差值的平均**。越大表示越分散。  
   （不是只說「差距」而不提絕對值與平均。）

2. **抽樣變異（Sampling Variation）**  
   從母體抽樣算出的統計量（樣本平均、樣本標準差），因樣本隨機性而與母體參數不同，這種變動叫抽樣變異。

3. **統計推論**  
   根據樣本資料，判斷是否接受或拒絕統計假設的過程。

4. **檢定對照表（常考陷阱）**

   |  | H0 為真 | H0 為假 |
   |--|---------|---------|
   | 接受 H0 | 正確 | Type II 錯誤（β） |
   | 拒絕 H0 | **Type I 錯誤（α）** | 正確 |

   勘誤重點：拒絕真的 H0 是 **Type I**，不是 Type II。

5. **K-means（指引 3-31 練習）**  
   原理**相對簡單**（反覆分配到最近中心、更新中心、最小化平方誤差）。常與 PCA、Elbow 結合。適合球形、大小密度接近的群。  
   「原理比其他集群法複雜」這句是錯的。

6. **p 值 0.03、α＝0.05**  
   正確說法：在 95% 信心水準下拒絕虛無假設。  
   - 不是「有 97% 信心」  
   - 不是「這次犯錯機率就是 5%」（5% 是你事先容許的 Type I 上限）

## 科目二

7. **3-32 第一段標題**  
   原「（3）資源與基礎設施評估」→ 改「**（3）企業導入階段性實施策略**」  
   內容是：試點 → 階段擴大 → 長期目標 → 持續優化。  
   「資源與基礎設施」仍是前面第（2）點，不要混。
