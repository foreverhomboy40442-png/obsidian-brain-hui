## 怎麼練（固定流程）

1. **遮答案**：紙或手遮左欄「答案」，先寫 A–D。  
2. **對完只記錯題**：抄到 [[錯題本]]，四行：題號、我選、正解、以後先問什麼。  
3. **回指引頁**：錯在統計→3.2＋勘誤；錯在 RAG→S2 3.2；錯在導入階段→S2 3.3＋勘誤標題。  
4. **隔天重測錯題**，不要重讀整份卷。

每科模擬：75 分鐘、50 題 → 約 1.5 分／題。長情境題先抓「問的是選技術、找錯誤、還是擋風險」。

## 出題方向（用這四份卷歸納）

### 題型

| 型 | 特徵 | 你要做的 |
|----|------|----------|
| 找錯誤 | 「何者有誤／不符合／最不適當／不屬於」 | 三個對的選項先打勾，剩下那個常是「把定義對調」 |
| 選技術 | 給場景（瑕疵、輿情、調度、客服） | 先問：有無標籤？要判定還是生成？要位置還是類別？ |
| 擋風險 | 個資、偏誤、幻覺、權限、出域 | 優先控制資料與人機責任，不是先換大模型 |
| 比方案 | RAG vs 微調 vs Prompt vs Low-Code | GPU 不夠→PEFT／LoRA；知識常改→RAG；規則固定→不必 Agent |

### 科目一在這兩場實際出現的主題

- 資料：整合目的、結構化、One-hot／編碼、正規化時機、離群值、SMOTE、視覺化（直方圖）
- 統計：平均／中位／標準差、常態與極端值（**必套勘誤**）
- 學習類型：非監督不是「對既定標籤學習」；強化學習要環境回饋；半監督用在標註少
- 生成／鑑別：產圖、摘要品質檢查、ChatGPT/Gemini 底層是 Transformer
- XAI：LIME、SHAP、Saliency、反事實（金融）
- 應用選型：分類 vs 偵測（煙霧要框位置）、CV vs NLP、窄域模型難直接泛化
- 推論：批次 vs 即時、LLM Batching、Flash Attention（概念題）
- 治理：金融 AI 對消費者揭露、個資去識別仍可能再識別
- 評量指標：醫院篩檢要降漏診 → 重視 Recall 那類思路

### 科目二在這兩場實際出現的主題

- 訓練資料偏差 → 先查樣本代表性
- PEFT／參數高效微調（資源不足時）
- Low-Code：儀表板可信度、權限稽核、邊緣端限制
- 延遲 vs 吞吐、長上下文、表格／Excel 餵 LLM
- RAG：chunk、法規更新要重建索引、與 MCP 不同
- Agent：情境感知、Solution Graph、何時不該上 Agent
- 工具：Copilot 類寫程式輔助、Sora 出處證明「何者不屬於」
- 導入：MVP、分階段（勘誤後的第 3 點）、風險與智財

115-2 比 115-1 **更偏 Agent／Low-Code／導入決策**。11/07 仍可能延續這個方向，所以 W6–W8 不能省。
